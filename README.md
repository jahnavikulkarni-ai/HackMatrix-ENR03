# HackMatrix-ENR03
Portable Microplastics Screening System for HackMatrix 5.0 ENR-03
The Portable Microplastics Screening System developed for HackMatrix 5.0 (ENR-03) is an accessible, low-cost optical triage framework designed to shift microplastic screening from centralized, capital-intensive laboratories directly into watershed communities and field stations. By coupling smartphone macro-optics and LED illumination with automated computer vision algorithms (utilizing Flask, OpenCV, and NumPy), the system enables rapid in-field particulate detection and counting at over 90% lower cost than traditional equipment. This decentralized workflow minimizes unnecessary laboratory spectroscopic workloads and delivers immediate preliminary visual identification for environmental monitoring and regulatory compliance.
